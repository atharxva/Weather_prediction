# 🌦️ Weather Rain Prediction ML Web Application

A full-stack Machine Learning web application that predicts whether it will rain tomorrow for any requested city across the globe. Built using **FastAPI**, **Scikit-learn**, **Open-Meteo API**, and a sleek modern dark-mode **Web Frontend**.

---

## 📌 Project Overview

This system provides real-time rain prediction by taking a city name, retrieving real-time atmospheric measurements from Open-Meteo API, preprocessing them into 12 core weather features, and feeding them through a trained Machine Learning model pipeline.

---

## ⚙️ How It Works (End-to-End Workflow)

```
[ User Input: City Name ]
           │
           ▼
[ Geocoding API (Open-Meteo) ] ────► Extracts Latitude, Longitude & Timezone
           │
           ▼
[ Forecast API (Open-Meteo) ]  ────► Retrieves Today's Meteorological Features
           │                             (Temp, Humidity, Pressure, Wind, etc.)
           ▼
[ Machine Learning Pipeline ]  ────► Preprocessing (Imputer + Scaler) + Model Predict
           │
           ▼
[ FastAPI Backend / Frontend ] ────► Returns Rain Prediction ("YES"/"NO") & Probability %
```

1. **User Request**: The user enters a city name via the Frontend UI or FastAPI REST API endpoint (`GET /predict?city=...`).
2. **Geocoding**: Converts the city name into geographical coordinates (`latitude`, `longitude`, `timezone`).
3. **Live Weather Data Fetch**: Requests real-time daily meteorological metrics for today's date from Open-Meteo API.
4. **Feature Engineering**: Formats the weather parameters into the exact 12 input features expected by the trained ML pipeline:
   - `temperature_2m_mean`, `temperature_2m_max`, `temperature_2m_min`
   - `relative_humidity_2m_mean`
   - `precipitation_sum`, `cloud_cover_mean`, `pressure_msl_mean`
   - `wind_speed_10m_max`, `wind_direction_10m_dominant`
   - `sunshine_duration`, `month`, `day_of_week`
5. **Model Inference**: The pipeline calculates the classification label (`YES` / `NO`) and probability score (`0% - 100%`).
6. **Result Display**: Renders the result instantly on the interactive Dark Dashboard UI or JSON response.

## 🤖 Model Training & Dataset

### 1. Data Collection (`src/data_collection.py`)
- Historical daily weather data (2020–2024) was collected from the Open-Meteo Historical Weather Archive API.
- Raw dataset includes daily temperature bounds, humidity, surface pressure, cloud cover, wind speed/direction, and precipitation metrics.

### 2. Feature Preprocessing & Target Definition
- **Target Variable (`rain_tomorrow`)**: Generated by shifting `precipitation_sum` by `-1` day (`precipitation_sum.shift(-1) > 0.1`).
- Missing values handled using `SimpleImputer(strategy="median")`.
- Continuous numerical features scaled using `StandardScaler`.

### 3. Training & Evaluation Pipeline (`notebooks/01_eda_data.ipynb`)
- Models trained & evaluated: **Logistic Regression**, **Random Forest**, **Gradient Boosting**, and **XGBoost**.
- Hyperparameters tuned using cross-validation to maximize ROC-AUC and F1 score while preventing overfitting.
- Model pipeline saved to disk at [`models/weather_model.joblib`](file:///Users/atharva/Desktop/Coding/AIML/Weather_prediction/models/weather_model.joblib).

## 🚀 Quick Start & Running Locally

### 1. Clone & Set Up Environment
```bash
# Clone repository
git clone https://github.com/atharxva/Weather_prediction.git
cd Weather_prediction

# Activate virtual environment
source myenv/bin/activate  # On macOS/Linux
# or myenv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt
```

### 2. Run the FastAPI Application
```bash
uvicorn app.main:app --reload
```

### 3. Open in Browser
- **Dashboard UI**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Swagger Interactive API Docs**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
